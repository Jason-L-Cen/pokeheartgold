The game owns one native `NSThread`, with requested `NSQualityOfServiceUserInteractive` set before `start`. UIKit queues input under a condition lock, and the owner applies it between display events. Frames are copied into immutable `NSData`; the main thread displays the latest frame without building a callback backlog. Backgrounding clears held input and suspends the owner and display clock. Foregrounding restarts the clock and observer. Scene disconnection requests the existing original reset/drain path before freeing the module. The original 512 KiB save is stored separately at `Application Support/HeartGoldOriginal/heartgold.sav`; prototype JSON saves are not migrated or overwritten.

The native owner also runs the original SDK's cooperative threads. Hardware frame capture continues on those workers, but display observers wait for an unmasked SDK root safe point and retain the latest pending presentation. This prevents the ordinary renderer from consuming a small cartridge-worker stack; it leaves the observer free to service audio, pause and reset at root. The real 1 KiB-worker regression reproduces stack exhaustion with the former gate and passes root rendering with the shared gate. See `work/native-presentation-root-check`.

Original 48 kHz stereo synthesis feeds `AVAudioEngine` through `AVAudioSourceNode`. The game copies borrowed PCM into an owned 8192-frame ring; the render callback consumes it using atomic cursors, without allocating, locking, calling the game, or reading module memory. Playback primes and reprimes after 2048 queued frames (42.67 ms at 48 kHz), adding 21.33 ms of startup/rebuffer latency to cover the measured producer/output-callback phase gap. Queue accounting follows frames actually read, avoiding false overflow from delayed player-completion callbacks. Statistics distinguish rejected frames from playback underruns and observe nonzero PCM before the final mute gain. Ambient audio respects the system's audio policy. Backgrounding and interruptions pause the native sound clock and engine, so resuming does not synthesize the background interval. An interruption without permission to resume, or headphone disconnection, waits for a user button press before resuming. Output failures are reported. New error-returning APIs are used on iOS 27, with iOS 16–26 compatibility paths.
